# AllToDo HomePage

AllToDo 서비스의 공식 소개 페이지(Landing Page) 리포지토리입니다.
빠르고 가벼운 **Vite**를 사용하여 개발되었으며, **GitHub Pages**를 통해 배포됩니다.

## 🚀 시작하기 (로컬 실행)
내 컴퓨터에서 화면을 미리 보고 싶을 때 사용합니다.

1. **프로젝트 폴더로 이동**
   ```bash
   cd AllToDo-HomePage
   ```

2. **의존성 설치 (최초 1회만)**
   ```bash
   npm install
   ```
   
3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   - 실행 후 터미널에 나오는 주소(예: `http://localhost:5177`)를 클릭하면 브라우저에서 확인할 수 있습니다.
   - 소스 코드를 수정하고 저장하면 화면에 즉시 반영됩니다.

---

## ✏️ 수정 방법
이 프로젝트는 단순한 HTML/JS 구조를 가집니다.

- **`index.html`**: 메인 페이지 구조와 텍스트 내용을 수정합니다. (타이틀, 문구 등)
- **`src/style.css`**: 디자인, 색상, 레이아웃을 수정합니다.
- **`src/main.js`**: 배경 애니메이션이나 인터랙션 로직을 수정합니다.
- **`public/assets/`**: 이미지 파일들은 여기에 넣습니다.

---

## 🚢 배포 방법 (수정 후 올리기)
수정한 내용을 실제 사이트(`alltodo.kr`)에 반영하려면 **빌드 후 커밋**해야 합니다.

### 1단계: 빌드하기
먼저 배포용 폴더(`docs`)를 최신 상태로 만듭니다.
```bash
npm run build
```
*(성공적으로 끝나면 `docs` 폴더 안의 파일들이 갱신됩니다)*

### 2단계: 커밋 및 푸시
변경된 소스와 빌드 결과물을 GitHub에 올립니다.

```bash
# 1. 모든 변경사항 담기
git add .

# 2. 커밋 메시지 작성 (예: 메인 문구 수정)
git commit -m "Update: 메인 문구 수정 및 재배포"

# 3. GitHub로 보내기
git push origin main
```

**끝났습니다!** 잠시 후(1~3분) `alltodo.kr`에 접속하면 변경된 내용이 보입니다.
